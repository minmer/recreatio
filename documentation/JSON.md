# JSON for every part

Every part of Recreatio that holds content can be exported and imported as one JSON document — by hand, from a
backup, or prepared by an assistant. The rules are the same everywhere (2026-10-29):

- **One panel** (`ui/JsonPanel.tsx`): export, import with the list of changes and warnings before the import
  button, and the description of the format beside it — copyable for an AI, with samples to insert.
- **The description is the format's tree** (`core/jsonTree.ts`): each node says its own keys and names the formats
  inside it. The same text is served to assistants over MCP (`list_import_formats`, `get_import_format`, MCP.md),
  generated by `frontend/scripts/import-formats.mjs` into `backend/Api/Library/ImportFormats.json`; `app-json-check`
  fails when that file lags behind the app.
- **Import changes in place**: what carries an `id` from an export is updated, what has none is created; nothing is
  deleted unless the format names a previewed way to remove. References inside a document use `"@key"`.
- **Sealing does not change**: an import saves through the same functions as the part's own editor — names, titles,
  notes are sealed in the browser. The exported file is plaintext; it is the user's own download.
- **Checks**: `app-json-check` (pages, modules, areas, forms, calendar schemes and plans, the MCP file) and one
  `app-json-<part>-check.mjs` per part below.

## The formats

| part | MCP id | where in the app | module |
|---|---|---|---|

| Biblioteka — a text for an existing work | `source-text` | dzieło → „Tekst źródła” → „Dodaj tekst (JSON)” | `library/sourceText.ts` |
| Biblioteka — quotes of a book | `quotes` | książka → „Cytaty z tej książki” → „Import cytatów z JSON…” | `library/libraryQuotes.ts` |

## Without import, on purpose

- **Sprawy** (reports): a report is a sealed letter in a signed chain (REPORTS.md); nothing is made from a file.
- **Konto keys, access links, AI links, seats**: they are secrets or made from secrets in the browser.
- **Administrator danych**: signed by a role with its certificate (DATA-CONTROLLER.md) — typed and signed in place.
